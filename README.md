# Training

Personal training website published with GitHub Pages.

Live site: https://phillipleroy.github.io/Training/

## What Is Included

- Mobile-friendly workout tabs for Treino A-E
- Weekly progress checklist saved locally in the browser
- Per-exercise completion checkboxes
- Embedded exercise videos where available
- Extra gym sessions for machines, dumbbells, cables, and conditioning

## Project Structure

- `index.html` - single-page training app
- `assets/` - app icons and favicon
- `scripts/` - supporting scripts, if needed

## Publishing

The site is hosted from the `main` branch of `phillipleroy/Training` through GitHub Pages. Updates are published by committing changes and pushing to `main`.
